# AlphaMagic assets (optional, but they make videos much better)

Drop files here. The video agent picks them up automatically, with no settings to change.

| Folder / file | What to put | Used for |
|---|---|---|
| `logo.png` | App logo, transparent PNG | Top-left of every scene + end card |
| `music/` | Royalty-free tracks (.mp3/.m4a) | Random background track per video |
| `clips/` | Real screen recordings of the AR app in action, vertical .mp4, 5–10 s | "Watch the Magic" videos (free, and real footage sells best) |
| `fonts/` | Brand font .ttf (e.g. `Baloo-Bold.ttf`) | On-screen text |

Music: use tracks you have rights to, such as the YouTube Audio Library (free to download) or your own.
Big files (clips, music) can use Git LFS, or live in shared storage later.
